# 📄 PDF AI Summarizer

A Streamlit app that summarizes PDF documents with **Google Gemini** via **LangChain**. Upload a PDF, pick a summary style, and get a summary, a document-structure analysis and optional key quotes.

## Features

- Text extraction, cleaning and token-aware chunking with `pypdf` + `tiktoken`
- Map-reduce summarization: every chunk is summarized, then merged into one cohesive summary
- Four summary styles: **brief**, **detailed**, **bullet_points**, **executive**
- Document structure analysis and verbatim key-quote extraction
- Retries with backoff on transient Gemini errors (429/5xx), plus per-chunk failure tolerance
- Export as a text report and per-chunk statistics as CSV
- Test suite with a mocked LLM, so CI runs without an API key

## How it works

```
PDF → extract text → clean → chunk (by tokens)
                                  │
                  ┌───────────────┼───────────────┐
                  ▼               ▼               ▼
             summary 1       summary 2   ...  summary N      (map)
                  └───────────────┼───────────────┘
                                  ▼
                        combine → final summary             (reduce)
```

## Requirements

- Python 3.10+
- A Gemini API key from [aistudio.google.com/apikey](https://aistudio.google.com/apikey)

## Setup

```bash
python -m venv .venv
source .venv/bin/activate        # Windows: .venv\Scripts\activate
pip install -r requirements.txt
cp .env.example .env             # then put your key in .env
```

`.env`:

```
GEMINI_API_KEY=your_key_here
GEMINI_MODEL=gemini-3.1-flash-lite
```

`GEMINI_MODEL` sets the default model; it can also be changed in the sidebar. The model list lives in `MODELS` in `app.py`.

## Run

```bash
streamlit run app.py
```

Open http://localhost:8501, upload a PDF and press **Process PDF**.

## Tests

```bash
pip install -r requirements-dev.txt
pytest
ruff check .
```

Tests use a fake LangChain runnable, so no API key or network access is needed. `samples/sample.pdf` is generated by `python scripts/make_sample_pdf.py`.


## Prompt templates

All prompts live in `prompts.py` as LangChain `ChatPromptTemplate`s (system + human message):

- `STYLES`: maps each summary type to its instruction text (injected as `{style}`)
- `_template(human)`: builds a template from the shared system message plus a human message
- `CHUNK_SUMMARY`: per-chunk summary prompt (takes `{style}` and `{text}`)
- `COMBINE`: merges chunk summaries into the final summary
- `ANALYSIS`: document structure analysis
- `QUOTES`: key quote extraction

To add a style, add an entry to `STYLES` in `prompts.py` and its name to the **Summary Type** options in `app.py`.

## Troubleshooting

| Symptom | Fix |
|---|---|
| `No extractable text` | The PDF is probably scanned images. Run OCR first. |
| 429 / rate limit errors | Wait a minute, use a smaller document, or pick another model. Retries are automatic but limited. |
| Model not available / 404 | Set `GEMINI_MODEL` to a model your key can access, or choose one in the sidebar. |
| API key not found | Make sure `.env` exists next to `app.py` and contains `GEMINI_API_KEY`. |
